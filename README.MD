# WizPlayer

Androidを主対象に、FC・GB/GBC・SFC向けの対象RPGを遊ぶためのエミュレータープレイヤーです。ゲームROMは付属しません。



## 対応ゲーム
- ファミコン版ウィザードリィ１・２・３
- スパーファミコン版ウィザードリィ５
- ゲームボーイ版ウィザードリィ外伝１・２・３
- ゲームボーイカラー版ウィザードリィ１・２・３
- ファミコン版ドラゴンクエスト３・４
- ゲームボーイカラー版ドラゴンクエスト３
- スパーファミコン版ドラゴンクエスト５
- ファミコン版ファイナルファンタジー２
- ファミコン版ファイナルファンタジー３
