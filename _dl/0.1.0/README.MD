## Android版

Android 8.0以上のarm64またはx86_64端末で使えます。対応機種はファミコン、スーパーファミコン、ゲームボーイ、ゲームボーイカラーです。


## インストールと起動

1. [WizPlayer-0.1.0-Android.apk](Android/WizPlayer-0.1.0-Android.apk) を端末で開き、インストールします。Androidから求められた場合は、APKを開いたアプリにインストールを許可してください。
2. 初回起動で `Documents` を選ぶと、`WizPlayer` フォルダが作成されます。既にある `WizPlayer` フォルダも選択できます。
3. ご自身で用意したROMを `Documents/WizPlayer/rom` に置き、アプリの一覧から選択します。「ROMフォルダを変更…」で別の場所も選べます。ROMは同梱していません。

通常セーブ、ステートセーブ、設定はそれぞれ `WizPlayer/save`、`WizPlayer/state`、`WizPlayer/settings` に保存します。署名の異なる開発版が入っていると上書きインストールできません。その場合は保存フォルダをバックアップした上で開発版をアンインストールしてください。

## 操作

- 画面のタッチボタン、またはXbox／Switch Proコントローラーで操作できます。
- コントローラーの左スティック押し込みで機能メニュー、LTでスロット1に保存、右スティック押し込みでスロット1を読み込みます。
- 対応するWizardryではRTでマップ、右スティック下でアイテム管理を開きます。戦闘中など、一部の場面では開けません。

## Windows x64版

[Windows x64版のZIP](Windows/WizPlayer-0.1.0-Windows-x64.zip) を展開し、`WizPlayer.exe` を起動して、ご自身で用意したROMを選択します。`SDL2.dll` は `WizPlayer.exe` と同じフォルダに置いてください。

Windows版で最後に選んだROMフォルダは、次回起動時に開きます。設定はROMごとに保存し、既存の通常セーブ・ステートは従来の保存先から読み込みます。

- F2で機能メニュー、F1でスロット1に保存、Shift+F1でスロット1を読み込みます。
- 対応するWizardryではF3でマップ、F4でアイテム管理を開きます。マップから位置を移動する前にスロット1に保存します。
- 対応ROMでは1.5・2・3・4・5・10倍でプレイでき、BGM・SEは等速です。攻略補助とキャラクター編集は機能メニューから開きます。
