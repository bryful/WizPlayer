Androidの既定ROMフォルダは `Documents/WizPlayer/rom`。ステートは `WizPlayer/state` に保存する。対応拡張子はFCの `.nes`・`.fc`、GB/GBCの `.gb`・`.gbc`、SFCコア組み込み時の `.sfc`・`.smc`。

- AndroidゲームパッドはLTでスロット1保存、右スティック押し込みで読込、RTでマップ、左スティック押し込みで機能メニュー、右スティック下でWizardryのアイテム管理。画面にも設定・保存・読込・マップ・アイテムなどのボタンがある。
- Windowsキーボードは矢印キー、A相当のX/Enter、B相当のZ/Esc、Space（Select）、Backspace（Start）、Q/W（L/R）、S/A（X/Y）。スロット1保存は1/F1、読込はShift+F1、機能メニューはF2、マップは2/F3、アイテムはF4。ゲーム側に送られるボタンは機種による。
- Androidキーボードの機能ショートカットはF1（機能メニュー）、F5/F8（スロット1保存/読込）、M/F3（マップ）、F4（アイテム）。

## 内蔵バグ修正パッチのON/OFF

AndroidとWindowsでは、対応ROMを選ぶと内蔵バグ修正パッチのON/OFFを選べる。プレイ時に用意するのはROMファイルのみ。リセット時は選択済みのON/OFFを保持する。切り替えるには同じROMを選び直す。

ONでは元のROMをメモリに読み込んでからパッチを適用し、OFFでは元のROMで起動する。対象は日本語版の対応する未改造ROM。通常セーブとステートの保存名はON/OFFで共通のため、ステートは保存時と同じ設定で読み込む。

| 対象 | 使用するIPS |
| --- | --- |
| FC Wizardry I | `wizardry_pg_fc_fix.ips` |
| GB Wizardry 外伝I | `wizardry_soq(gaiden1)_fix.ips` |
| GB Wizardry 外伝II | `wizardry_cae(gaiden2)_fix.ips` |
| GB Wizardry 外伝III | `wizardry_sod(gaiden3)_fix.ips` |
| GBC Wizardry I〜III | `Wiz GBC I-III BugFix (2018-12)` の `GBC Wizardry - bug fix` にある各作品用の `_fix.ips` |

ビルド時に `.patch` から上記7本を取り込む。素材がないビルドでは、その作品のON/OFF選択は表示されない。Android 0.1.0の配布版は、著作権放棄済みのこの7本を組み込む。

## 確認状況

- Android実機では、GB外伝Iの起動・ステートの再読込、FC/SFCの起動、全10作品のWizardryマップの踏破色・現在地表示、FC Wizardry I〜IIIとSFC Vのアイテム操作・キャラクター編集の確認記録がある。SFC Vではマップ移動とスロット1での復元も確認済み。
- Androidの等速音声は各機種のコアで確認済み。FC Wizardry I〜IIIは実機のPCM出力も確認済み。全作品の聴感・長時間の最大倍率、追加した攻略補助の実機での通し操作や報酬受け取りは未確認。
- WindowsはFC対象7作品・SFC対象2作品とGB外伝Iで、映像出力とステートの往復に確認記録がある。今回のWindows x64 Releaseビルドで、GB外伝I、FC Wizardry I、SFC Wizardry Vの映像出力とステートの往復を確認。新規メニューのGUI通し操作は未確認。
- SFCの全ROMリビジョンでの判定と旧ステートの互換範囲は未確認。
